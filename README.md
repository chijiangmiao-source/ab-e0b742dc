# 冗余离散链路瞬态复核台

面向航电冗余离散链路维修复核：在开关抖动（外部边沿序列）之后，检查关键输出是否出现
**过短脉冲**或**持续振荡**，避免只凭最终电平遗漏瞬态故障。

纯 Node.js（无第三方依赖），引擎同时可在浏览器中运行。

## 功能

- 页面录入：最多 12 个唯一标识的 `NOT / AND / OR` 门、正整数惯性延迟、输入连线、
  外部边沿表、受监控输出；可**提交复核**或**清空草稿**（草稿本地保存）。
- 同刻事件按固定顺序稳定处理：外部边沿（按连线名）→ 到期内部事件（按事件标识）→
  受影响门按标识重算一次，再跳到下一相关刻度。
- **惯性延迟与待发事件撤销**：门输入变化后重新计时；目标值回到当前值时撤销待发翻转
  （invalidated），期望翻转改变时旧事件被取代（superseded）；失效翻转绝不落入轨迹。
- 校验逐项报错并清除旧结论：悬空连线、重复驱动（外部边沿驱动门输出）、非法边沿
  （时刻/目标值/重复）、环内零延迟、门标识重复/超量、延迟非正整数等。
- 边沿窗口结束后：
  - 事件队列排空 → 展示**静稳结论**（初值/最终值、轨迹、撤销记录）；
  - 若 `(稳定门值, 相对待发事件)` 签名重复 → 判定**振荡**，按稳定门值和事件标识给出
    **可回放的振荡前缀与循环**（页面可逐帧/自动回放）；
- 关键输出上宽度 ≤ 2 刻度的**短脉冲**显示起止刻度、宽度，并附递归展开到外部边沿根因的
  **因果事件链**。
- **重复配置识别**：对规范化（排序后的门/边沿/监控、初值与相对待发事件）配置计算签名，
  相同签名提示历史重复。
- `GET /health` 返回 `{status:"ok"}`；宿主端口可通过 `PORT` / Compose 的 `HOST_PORT` 配置。

## 目录

```
src/engine.js         仿真引擎（Node + 浏览器通用）
public/               页面（index.html / app.js / styles.css；engine.js 由构建发布）
scripts/server.js     静态服务 + /health
scripts/build.js      页面构建（发布浏览器版引擎并校验资源）
scripts/verify.js     一次性验收服务
test/engine.test.js   引擎代码测试（node:test，8 项）
docker-compose.yml    Compose（含 verify profile）
Dockerfile
```

## 本地运行（无需 Docker）

```bash
node scripts/build.js          # 发布 public/engine.js
npm start  # 或 PORT=9090 node scripts/server.js
# 浏览器打开 http://localhost:8080
```

## Compose

```bash
HOST_PORT=9090 docker compose up --build      # 可配置宿主端口
docker compose --profile verify run --rm verify   # 一次性验收，以退出码报告
```

## verify 验收顺序

1. **A1** 宽度 2 的短脉冲：起 3、止 5、宽 2，因果链回溯到 `ext:in@1` 与 `ext:in@3`；
2. **A2** 延迟 3 的 NOT 门在第 0、1 刻反转 → 第 3 刻失效翻转被撤销，轨迹无翻转，终态正确；
3. **A3** 正延迟反馈链（三级延迟 1 反相器环）→ 振荡，前缀/循环可回放，待发事件带标识与相对时刻；
4. **B** 运行 `node --test test/` 代码测试；
5. **C** 完成页面构建；
6. **D** 启动服务进行 `/health` 与首页 HTTP 冒烟；
   全部通过退出码 0，任一失败退出码 1。

```bash
node scripts/verify.js
```

## 仿真语义要点

- 外部输入初始为 0；无环门从全 0 种子松弛到不动点作为规范化初值。
- 反馈环用 Tarjan SCC 识别：有不动点的环取不动点；无不动点的环（如奇数个反相器）
  从全 0 上电种子在第 0 刻注入首批惯性翻转，之后完全由事件机制演化。
- 振荡判据在外部边沿窗口结束后启用：签名 = `门值 | 门:目标@相对最早到期偏移`，重复即循环。
- 短脉冲分析在受监控连线的分段轨迹上进行；同刻内初始化造成零宽段不计为脉冲。
